# Docs (AV Call Button)

Living notes for product direction and feature build-out. Prefer updating these over burying decisions in chat history.

| Doc | Purpose |
| --- | --- |
| [`architecture.md`](./architecture.md) | Current system map (monorepo, stack, domain) |
| [`vision.md`](./vision.md) | Where the product is headed (near-term + later) |
| [`room-alert-dashboard.md`](./room-alert-dashboard.md) | **Active build:** room alerts + crew dash MVP + progress |
| [`chat-plan.md`](./chat-plan.md) | Chat feature plan + progress |

## How to use in a new agent chat

> Read `docs/architecture.md` for system context. For product direction, read `docs/vision.md`. For the room alert / crew dash work, follow `docs/room-alert-dashboard.md` and update its Status checklist as work lands.
